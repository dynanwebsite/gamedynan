# ⚔️ Eternal Realms

Action RPG top-down bergaya Genshin Impact / Wuthering Waves.
Dibuat dengan HTML5 Canvas + JavaScript murni (tanpa library).

## 🎮 Kontrol
- **WASD / Arrow** = Gerak
- **Mouse** = Arah serang
- **Klik Kiri** = Serangan dasar
- **Q / E / R / F** = Skill
- **Space** = Dash
- **Shift** = Sprint
- **ESC** = Pause

## 🚀 Cara Menjalankan
Cukup buka `index.html` di browser modern.

## 📁 Struktur
- `index.html` — markup
- `style.css` — tampilan
- `js/config.js` — data karakter & monster
- `js/utils.js` — helper
- `js/input.js` — kontrol
- `js/entities.js` — kelas Player, Monster, Proj
- `js/skills.js` — sistem skill
- `js/waves.js` — spawn & wave
- `js/hud.js` — UI
- `js/game.js` — engine utama

## 🌐 Deploy ke GitHub Pages
1. Push semua file ke repo GitHub
2. Settings → Pages → Source: `main` / `root`
3. Buka `https://username.github.io/nama-repo/`
